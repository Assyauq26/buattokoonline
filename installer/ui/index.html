Untuk subdomain, gunakan label subdomain pada zona DNS induk, bukan @. Jika mengaktifkan www, tambahkan CNAME www ke domain utama. Hapus hanya A/AAAA yang bertentangan untuk nama host toko.

Cara mengatur DNS
  1. Login ke penyedia domain.
  2. Buka DNS Management / DNS Zone.
  3. Tambah atau ubah A Record untuk toko.
  4. Masukkan IP VPS di atas.
  5. Simpan konfigurasi.
  6. Kembali ke installer.
  7. Klik “Periksa Koneksi Domain”.

Hostinger: Domains → kelola domain → DNS / Nameservers. Cloudflare: pilih domain → DNS → Records; gunakan DNS-only saat pemeriksaan awal. IP proxy Cloudflare bukan IP VPS. Penyedia lain: cari DNS Zone atau DNS Management.

Biarkan record MX/email dan record lain yang tidak berkaitan. Installer tidak meminta password penyedia DNS.

Buat Akun Administrator Toko
Akun ini dipakai untuk mengelola produk dan pesanan di tokomu.
Minimal 12 karakter, maksimal 72 byte. Gunakan tiga jenis karakter: huruf kecil, huruf besar, angka, atau simbol. Password tidak disimpan dalam progres instalasi.
