# Buat Toko Online Sendiri

Template aplikasi toko online mandiri, dikembangkan dari aplikasi toko Gheverhan.

> **Status: sedang disiapkan — belum dapat diinstal.** Repository ini baru diinisialisasi. Jangan menjalankan installer atau menganggap sudah tersedia sebelum source aplikasi yang dibersihkan, skrip `install.sh`, dan pengujian instalasi benar-benar diterbitkan.

## Tujuan

- Aplikasi toko saja (storefront dan dashboard admin), bukan portal pendaftaran/superadmin BTOS.
- Toko baru dimulai dengan produk, pelanggan, transaksi, dan media kosong.
- Pada instalasi pertama, pemilik menentukan nama brand, domain, dan kredensial administrator toko di server miliknya sendiri.
- Data toko (PostgreSQL, media, config/secrets) disimpan terpisah dari kode dan dipertahankan ketika update.
- Source master pengembangan: [Gheverhan](https://github.com/Assyauq26/Gheverhan).
