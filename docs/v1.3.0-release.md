# v1.3.0 — Pengelolaan toko dan akun pelanggan

## Perubahan
- Banner Hero tetap dapat diedit melalui Dekorasi Toko, tanpa menu duplikat.
- Menu Lainnya mobile mendukung klik luar, Escape, toggle dan perpindahan halaman.
- Daftar produk ringkas dengan pencarian, kategori, status, pagination dan menu aksi.
- Hapus produk mengarsipkan produk berhistori; penghapusan aman menjaga transaksi dan antrean pembersihan media.
- Rekening pembayaran dapat diedit, dinonaktifkan dan dihapus dari pilihan baru. Pembayaran lama tetap menyimpan versi rekening semula.
- Pembatalan J&T ditampilkan terpisah dari pembatalan pesanan/refund. Resi ulang hanya sesudah pembatalan terkonfirmasi, dengan arsip setiap percobaan. Status UNKNOWN harus direkonsiliasi.
- Seller dapat mengelola profil/status customer dan meminta email pemulihan, tanpa memilih password atau mengganti email customer.
- Customer dapat mengelola profil, password dan alamat. Penghapusan akun memerlukan autentikasi ulang, menjaga histori transaksi dan mencabut sesi.

## Instalasi dan update
Instalasi baru menggunakan paket rilis standar. Update dari versi lama memerlukan review operator untuk tiga migrasi baru; updater otomatis tetap menolak SQL di luar grammar aman. Jangan menjalankan bootstrap ulang atau mereset database.

Pengujian J&T menggunakan transport mock, tanpa membuat atau membatalkan resi produksi. Tidak ada perubahan desain beranda v1.2.1 maupun konfigurasi kredensial seller.

## Urutan deployment Hubify
1. Simpan image relay dan aplikasi lama serta konfigurasi root-only.
2. Build relay dari commit final; jalankan tes relay. Aktifkan relay yang mendukung notifikasi `customer-changed`, menggunakan secret dan volume yang sudah ada. Periksa health; rollback image jika gagal.
3. Jalankan `sudo python3 /path/to/hubify-v130.py COMMIT_SHA` dari `deploy/hubify-v130.py` yang telah direview. Script membatasi target Hubify dan baseline v1.2.1, memverifikasi ledger, membuat backup, memulihkan salinan database, dan menguji migrasi tanpa kehilangan jumlah data bisnis.
4. Build selesai sebelum aplikasi dihentikan. Backup final dibuat setelah penghentian aplikasi/timer; migrasi diterapkan, akses runtime diperbarui, lalu aplikasi diaktifkan dan health publik diperiksa. Platform pusat dan DNS tidak berubah.
5. Periksa navigasi, produk, rekening, customer/account dan halaman pesanan. Jangan menjalankan operasi carrier produksi sebagai smoke test.

## Rollback
`sudo python3 /path/to/hubify-v130.py --rollback` memulihkan Compose/image aplikasi sebelumnya dan timer. Kolom/tabel additive tetap dipertahankan; data baru tidak dihapus. Metadata mencatat versi kode lama dengan inventaris migrasi aktual. Script berhenti jika ledger migrasi tidak konsisten. Backup database, media, konfigurasi dan journal tersedia di VPS; jangan memulihkan backup ke database aktif tanpa menilai transaksi setelah deployment.

## Validasi

PR akun menambahkan browser Chromium pada 360, 390, 768, 1024, 1280, 1440 px. Tidak tersedia script lint terpisah dalam repository. Bukti CI dan screenshot disimpan sebagai artifacts; hasil deployment dicatat terpisah setelah aktivasi.
