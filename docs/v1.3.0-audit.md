# Audit dan rencana v1.3.0

Baseline: 8f8652b (v1.2.1). Data produksi tidak direset. Tidak ada request carrier produksi untuk pengujian.

| Area | Temuan | Penanganan dan gate |
|---|---|---|
| Banner | Link hero didaftarkan terpisah dan pada Dekorasi | Hapus hanya entri navigasi; pertahankan route, editor, izin dan data |
| Lainnya | Native details tidak mengelola outside click, Escape atau perpindahan route | Popover nonmodal dengan fokus, toggle, dismiss dan cleanup listener; tes browser |
| Produk | Harga/aksi pindah baris pada mobile, stok/filter kategori belum tersedia | Baris horizontal, menu aksi, filter kategori, pagination; query berizin |
| Hapus produk | Hanya perubahan status tersedia; relasi order/variasi/media kompleks | PRODUCT_DELETE, transaksi/konkurensi, arsip bila memiliki histori; jangan cascade order |
| J&T | Cancel hanya mengganti request state dan notes, shipment masih PENDING; orderId request tunggal | State pembatalan eksplisit, riwayat percobaan, UNKNOWN fail-closed, next actions; mock carrier, audit dan tes konkurensi |
| Bank | Edit/hapus belum tersedia; Payment mereferensikan rekening langsung | Versi rekening immutable bila pernah dipakai; nonaktifkan versi lama, transaksi dan audit |
| Pelanggan seller | Daftar mencakup staf, tidak ada izin mutasi pelanggan | Pisahkan customer/staf, permission khusus, tidak mengubah email/password oleh seller; reset melalui email |
| Akun customer | Profil/alamat hanya baca, sesi dapat dicabut lewat sessionVersion | Ownership, reauth/rate limit, alamat terverifikasi mapping, anonymization tanpa mengubah snapshot order |

Urutan PR: A navigasi/daftar produk; B penghapusan produk/rekening; C J&T cancellation; D pelanggan/akun. PR C dan D terpisah. Migrasi hanya additive bila diperlukan; review schema dan hak DB sebelum deploy. Perubahan bank tidak boleh mengganti informasi rekening pada pembayaran lama. Penghapusan akun ditolak saat ada kewajiban order/refund aktif.

Gate tiap PR: typecheck, unit/integration/security, review diff dan CI. Gate akhir: build, database/konkurensi, browser 360/390/768/1024/1280/1440, regression checkout/email/shipping, backup dan rollback. Pengujian dilakukan pada database disposable dan mock J&T; tidak membuat AWB produksi. Deploy Hubify memakai backup data/config dan image lama; migrasi kompatibel, rollback kode tanpa menghapus data baru. Rilis hanya setelah seluruh gate kritis terbukti PASS.
