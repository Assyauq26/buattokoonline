# v1.4.0 — Akun, pesanan dan label pengiriman

- Autentikasi customer memakai tema toko; pemulihan seller ditampilkan hanya pada konteks seller.
- Akun customer berisi profil ringkas, jumlah pesanan aktual, shortcut dan pengaturan profil/alamat/keamanan terpisah.
- Pesanan customer menyediakan pencarian, filter status, informasi produk dan tindakan pembayaran/tracking sesuai status.
- Pesanan seller memakai kartu ringkas, filter bottom sheet (status, tanggal, pembayaran, pengiriman), search dan sort.
- Pengiriman checkout menggunakan skeleton dan menyembunyikan tarif stale selama perhitungan; validasi tarif server tetap berlaku.
- Resi J&T yang dibatalkan tidak ditampilkan aktif pada halaman customer. State machine cancel/reissue v1.3.0 dipertahankan.
- AWB tersedia sebagai PDF tetap 100x150 mm, logo resmi dalam warna thermal monokrom, nomor penerima tersensor, QR/Code128, rincian barang tepat di bawah Order ID.

Tidak ada migrasi database atau perubahan kredensial. Pengujian carrier memakai mock, tidak membuat/membatalkan resi produksi. Pengujian printer thermal fisik dan viewer Android fisik memerlukan pengecekan perangkat pengguna; ukuran PDF dan decoding barcode diperiksa otomatis.

Rollback menggunakan image/Compose v1.3.0 dan konfigurasi sebelumnya tanpa memulihkan/reset database. Simpan backup database/media/config sebelum aktivasi. Updater wajib memverifikasi SHA, paket dan inventaris migrasi yang identik.
