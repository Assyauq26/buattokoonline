# v1.5.4 — Grid rekomendasi halaman produk

Pemeriksaan screenshot live menemukan aturan CSS kartu lama yang memaksa grid rekomendasi menjadi satu kolom pada mobile, terutama kartu harga diskon. Markup dua kolom saja tidak mengalahkan selector tersebut.

| Before | After | Why |
| --- | --- | --- |
| Rekomendasi mewarisi aturan global kartu satu kolom/wide-price | Grid khusus PDP menetapkan dua kolom mobile dan empat desktop; kartu harga panjang tidak membentang ke seluruh baris | Sesuai mockup tanpa mengubah grid beranda atau katalog |

Pengujian browser memeriksa jumlah kolom dan override wide-price pada 360/390/430/1440 px, selain zoom galeri beberapa foto, variasi, keranjang, buy-now dan Pengaturan. Build/typecheck dan pemeriksaan browser dijalankan lokal, tanpa CI. Smoke publik diulang pada produk sebenarnya sesudah deployment.

Seluruh fitur v1.5.2 dan perbaikan galeri v1.5.3 dipertahankan. Tidak ada perubahan backend, database, dependency, OTP, J&T, DNS atau data toko. Backup/image v1.5.3 dipertahankan; rollback patch ini tidak memulihkan database. Jangan rollback melewati parser konfigurasi v1.5.2 setelah field identitas baru disimpan.
