# v1.5.3 — Area klik galeri beberapa foto

Smoke browser live v1.5.2 menemukan area indikator galeri beberapa foto menutupi tombol Perbesar. Fixture browser sebelumnya hanya memiliki satu foto, sehingga masalah tersebut tidak terdeteksi lokal.

| Before | After | Why |
| --- | --- | --- |
| Container indikator transparan menangkap klik di atas tombol Perbesar | Area transparan melewatkan pointer; hanya tombol foto menerima klik, dan indikator dipisahkan dari zoom/counter | Zoom, indikator dan penghitung tetap dapat digunakan tanpa tumpang tindih |

Fixture browser kini memiliki dua foto dan memeriksa hit target tombol zoom pada 360/390/430/1440 px. Seluruh fungsi v1.5.2 dipertahankan. Tidak ada perubahan backend, SQL, dependency, email, J&T, DNS atau konfigurasi toko.

Pemeriksaan: build/typecheck, enam tes galeri, enam guard deployment dan 25 skenario browser dengan database lokal terpisah lulus. Sesudah deployment, smoke browser diulang pada foto produk Hubify sebenarnya, termasuk reduced motion. Hasil deployment dan screenshot dicatat dalam laporan rilis operator. Tidak ada transaksi, pesan, atau request kurir nyata.

Rollback khusus patch ini dapat mengembalikan image v1.5.2 sambil mempertahankan database dan konfigurasi terbaru. Kedua versi memahami identitas JSON yang sama. Jangan rollback melewati v1.5.2 setelah field identitas baru disimpan. Kebijakan paket umum `rollback_compatible: false` dipertahankan.
